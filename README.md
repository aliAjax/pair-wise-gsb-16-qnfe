# hxwl-01 助听器试戴回访调度台

门店听力师的助听器试戴回访预约与改期调度台。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 调度规则

- 每名客户按初配日自动生成第 1、7、30 天三个回访节点，节点日固定
- 临时改期只能提前或顺延，不能跨过后续节点日
- 已完成节点锁定，不得改期或覆盖
- 门店同一日期 + 时段只能接待一人
- 改期成功后原时段立即释放
- 冲突时列出占用客户、节点日与原时段
- 预约与完成记录通过 localStorage 持久化，刷新页面后保持不变
